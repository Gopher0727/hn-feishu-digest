# 双机日报实施方案

保留默认 local 模式。company 模式通过 TASK_ROLE 选择 collector 或 consumer。
采集端 08:30（09:30、10:30、11:30 补偿），消费端沿用 09:27 至 12:27。
通过指定私有 GitHub 数据仓库 daily/YYYY-MM-DD.json 发布不可覆盖的日资料包。
包包含 schema_version、日期、正文条目、下一天 backlog、已选 ID 和 SHA256 指纹。
采集端读取最近已发布包恢复 backlog/去重信息；个人电脑与 Actions 同日竞争时使用 GitHub 创建文件的原子冲突检测，已发布者胜出。
消费端校验日期、结构、指纹、正文门槛与唯一 ID，只读取包，不访问原站。
消费开始后固定输入指纹，所有模型摘要完成后发送并保存发送断点。
同机以 OS 文件锁隔离手动和定时运行。两台消费机器不应同时启用。
llama.cpp provider 允许 HTTP、可选 key、可配置 JSON 输出开关；DeepSeek 默认行为保留。
